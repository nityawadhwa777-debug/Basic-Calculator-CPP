Basic Calculator Using C++

About the Project

This is a beginner-level basic calculator developed using C++. It performs basic arithmetic operations on two numbers.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling

Technologies Used

- C++
- Visual Studio Code
- g++ Compiler

Concepts Used

- Variables and data types
- Input and output
- Switch-case statements
- If-else conditions
- Arithmetic operators

How to Run

1. Open the project folder in Visual Studio Code.
2. Compile calculator.cpp using a C++ compiler.
3. Run the compiled program.
4. Enter two numbers and an operator.
5. View the result in the terminal.
